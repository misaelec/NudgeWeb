# Nudge Web

A web-based demo of the Nudge iOS app - your personal growth companion.

## Features

- **Focus Mode**: Pomodoro timer with session tracking
- **Calendar**: Event management with monthly view
- **Reminders**: Create and manage reminders with priorities
- **Journal**: Write daily reflections
- **Objectives**: Track OKRs and key results
- **Fear Setting**: Tim Ferriss methodology for overcoming fears

## Tech Stack

- **Framework**: Next.js 14 (App Router)
- **Styling**: Tailwind CSS with Apple-inspired design
- **State Management**: Zustand with localStorage persistence
- **Icons**: Lucide React
- **Date Handling**: date-fns

## Getting Started

1. Install dependencies:
   ```bash
   npm install
   ```

2. Run the development server:
   ```bash
   npm run dev
   ```

3. Open [http://localhost:3000](http://localhost:3000) in your browser.

## Deployment

This project is ready to deploy on Vercel's free tier:

1. Push to GitHub
2. Import project in Vercel
3. Deploy - no additional configuration needed

## Authentication

This demo uses a mock authentication system for demonstration purposes. Data is stored in localStorage.
